# validation-app-practice

## 概要

COACHTECH 教材 Tutorial 9-6「バリデーション ハンズオン演習」で作成した成果物です。
フォームリクエストを使ったバリデーションと日本語エラーメッセージを備えた「ユーザー登録フォーム」を作成しました。

## 使用技術

- PHP 8.5.8
- Laravel 10.50.3
- Laravel Sail（Docker）
- Laravel Form Request（入力検証）
- Blade（テンプレートエンジン）
- Eloquent ORM（データベース操作）

## 学んだこと

- **Form Requestによる入力検証の仕組み**  
  `rules()` で入力条件を設定し、`messages()` でエラー時の日本語メッセージを指定する方法を学びました。また、`StoreUserRequest` をコントローラーで受け取ることで、入力検証と登録処理を分けられることを理解しました。

- **検証済みデータを使った登録処理**  
  `$request->validated()` で検証を通過したデータを取得し、Eloquentの `create()` で保存する流れを学びました。以前の教材で使った処理を、今回のユーザー登録にも応用できることが分かりました。

- **フォームとルーティングのつながり**  
  登録フォームの表示にはGET、データの送信にはPOSTを使用しました。動作確認中にルートが見つからないエラーが発生したことで、Blade側の `route()` と、ルーティング側の `name()` が対応している必要があることを学びました。

## 動作確認

1. Laravel Sailを起動する。
2. ブラウザで http://localhost/register にアクセスする。
3. 未入力で送信すると、日本語のエラーメッセージが表示されることを確認する。
4. 正しい情報を入力すると、ユーザー登録が成功し、完了画面が表示されることを確認する。
5. 登録済みメールアドレスを入力すると、重複エラーが表示されることを確認する。
